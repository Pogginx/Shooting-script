# 剧本切镜与生成批次

## 三层结构

始终区分：

```text
场次 Scene
└── 生成批次 Generation Unit
    └── 母版镜头 Shot / 内部节拍 Beat
```

- **场次**：由地点、时间和连续行动定义。
- **母版镜头**：真实剪辑层级，摄影机连续记录的一段画面。
- **生成批次**：一次模型生成或延长任务，可包含一个长镜头、多个切镜或多个内部节拍。

不要把“每个母版镜头都单独生成”或“每个生成批次只有一个镜头”当成默认规则。

## 切割算法

### 1. 标记不可丢失的叙事节拍

逐段标记：

- 新信息第一次出现；
- 人物目标、情绪或权力关系改变；
- 动作进入准备、发力、接触、反应或恢复的新阶段；
- 视角必须切换才能看清的新信息；
- 场景、时间、天气或声音状态变化；
- 需要成为上一批尾锚或下一批首锚的画面。

### 2. 把文学句变成可见事件

每个节拍用以下句式重写：

```text
[主体] 在 [可确认空间位置] 进行 [可见动作]，
摄影机从 [机位/景别] 以 [运动] 观察，
动作结束在 [可剪辑的镜尾状态]。
```

无法拍摄的心理活动必须落到表演或信息上。

### 3. 决定是否切镜

满足任一条件时通常切镜：

- 观众必须看到新的关键视觉信息；
- 表演重心从说话者转到听者；
- 动作尺度变化，需要全景证明空间或特写证明细节；
- 视线、道具或危险源必须被揭示；
- 当前构图无法同时清楚表达动作与反应；
- 有明确的动作匹配、视线匹配、声音先导或遮挡转场机会。

不要仅因为时间经过三秒或想“丰富画面”而切镜。

### 4. 分配镜头时长

以下是制作启发，不是平台硬限制：

| 镜头功能 | 常见可用时长 |
|---|---:|
| 极短插入、冲击点、道具信息 | 1–2 秒 |
| 简单动作或单一反应 | 2–4 秒 |
| 关系、对白、表演变化 | 3–6 秒 |
| 复杂调度或连续动作 | 5–10 秒 |
| 有动机的一镜到底 | 按完整动作链分配 |

短时长只适合单一清晰事件。不要在 4 秒内同时要求角色起身、奔跑、打斗、说长台词、换场和情绪反转。

### 5. 检查对白可说性

先按真人表演估算，再给呼吸、停顿和反应留余量：

- 中文自然对白可先按每秒约 3–4 个汉字估算；
- 英文自然对白可先按每秒约 2–3 个词估算；
- 哭腔、耳语、威胁、犹豫或多人抢话需要更长；
- 对口型镜头前后各保留少量表演缓冲，不让第一帧就开口、最后一帧才停。

如果时间不足，优先删冗词、改画外音或拆到相邻镜头，不靠异常语速硬塞。

### 6. 规划对白覆盖

先做对白覆盖图，再决定正反打和反应镜头。至少记录：

```text
台词段 / 说话者 / 说话者在画或 O.S. / 主覆盖镜头 /
允许的反应或动作插入 / 回到说话者的节点 / 口型要求
```

- 短台词：通常用说话者单人主镜头，或从听者肩后看向说话者的过肩镜头完整覆盖。
- 长台词：开场先确认说话者；在语义重音、停顿、信息转折或听者状态改变时，才切听者反应、动作/表情特写、相关道具或在场 NPC 的错峰反应；关键信息或收尾回到说话者。
- 从说话者肩后拍听者时，画面主体是听者反应，继续的说话者音轨标记 `O.S.`；只有重新切回说话者在画内实说时才恢复口型要求。
- 反应插入必须提供新信息，例如隐瞒、被刺痛、怀疑、权力退让或动作决定。重复的空表情、与剧情无关的空镜和凭空出现的 NPC 不能用来填满长台词。
- 多人反应按关系重要性错峰：直接受影响者先，隐藏利益相关者后，背景 NPC 最后且更克制。禁止同步点头、同步转头、同步笑。
- 对白音轨跨镜保持语气、距离、混响和环境声连续；不要因为切反应镜头而让音色、音量或空间感重置。

如果长台词需要多个反应镜头，用以下顺序作为启发，不要求全部使用：

```text
说话者主镜头 → 听者反应过肩 → 听者动作/表情特写 →
在场 NPC 错峰反应 → 回到说话者主镜头或说话者过肩镜头
```

说话者覆盖仍是主体。不要把一条关键台词剪成只听声音、不见说话者的反应蒙太奇。

## 组织生成批次

### 适合同批

相邻镜头同时满足大部分条件时可同批：

- 同一地点与时间；
- 主角色集合稳定；
- 服装、妆发、道具归属不变；
- 灯光方向和天气不变；
- 动作、视线或声音存在直接因果；
- 参考素材职责兼容；
- 有清晰的遮挡、动作、视线、形状或声音连接点。

### 应该拆批

出现以下任一高风险信号时拆批：

- 地点、时间、季节、天气或视觉媒介突变；
- 同一人物身份、年龄、服装或伤势发生显著变化；
- 新批次需要完全不同的参考视频运镜或动作；
- 角色数量、复杂互动或素材映射已经超过可稳定描述范围；
- 镜头包含互相矛盾的摄影指令；
- 需要先审定关键表演、产品落版、特效或高潮再继续；
- 已达到所选模型/入口的单次时长上限。

### 2.5 批次预算

- 30 秒内可完成多镜头起承转合，不要机械拆成两个 15 秒批次。
- 4–10 秒简单任务：1 个连续镜头或 2–3 个节拍。
- 11–30 秒叙事任务：用整数秒区间覆盖整批；官方示例可达到约 9 镜/30 秒，但镜头数量必须服从动作复杂度。
- 多主体复杂动作、精细口型或高一致性项目应减少镜头和事件密度。
- 要严格执行多个构图时，先制作独立关键帧；多宫格只作高层顺序参考。

### 2.0 批次预算

- 以最长 15 秒的兼容单元规划。
- 通常 3–5 个镜头/节拍；复杂打斗、多人表演或场景转换时更少。
- 使用“镜头 N”而不是精确秒段，把时长用于母版和剪辑校验，不把精确秒点写进最终 2.0 提示词。

下一批首镜必须从上一批的结束状态继续，或明确写出允许的转场/时间跳跃。

## 时间线验证

母版分镜使用全片连续时间，禁止每批重新从 `00:00` 计时。生成提示词内部可以使用批次局部时间。

需要脚本验证时，把母版镜头导出为 TSV：

```text
S001	0	3.5
S002	3.5	7.0
S003	7.0	12.0
```

运行：

```bash
python3 scripts/validate_timeline.py --target 12 timeline.tsv
```

脚本检查编号重复、顺序、负时长、重叠、空档和总时长；创作判断仍需人工检查。
