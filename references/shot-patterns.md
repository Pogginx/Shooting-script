# 常用镜头结构

只在当前场景需要时套用。模板是叙事结构，不是固定镜头数量。

## 多人反应

目标：让观众读懂群体关系，避免所有人同时夸张反应。

1. 建立镜头交代人物站位与主轴线。
2. 触发镜头明确谁说了什么或发生了什么。
3. 第一反应给最直接受影响者，用眼神、呼吸或重心变化。
4. 第二反应给隐藏利益相关者，用更克制且不同的动作。
5. 回到核心人物，让他/她看见或错过这些反应。

保持反应错峰；每人只设计一个主要可见变化。多人批次不稳定时，把关键反应拆成独立母版镜头或关键帧。

## 对白正反打

### 默认覆盖优先级

1. 双人中景建立左右关系、视线、距离和道具位置。
2. 角色开始说话后，优先使用说话者单人主镜头，或从听者肩后拍说话者的过肩镜头。说话者口型清楚可见，承担台词开场、关键信息、情绪转折和收尾。
3. 短台词通常不切离说话者。台词较长时，只在语义重音、停顿、信息转折或听者状态改变处切反应，不按固定秒数机械切镜。
4. 关系变化后可回到双人镜头收束，显示距离、站位或权力位置已改变。

说话者覆盖在整段对白中应占主体。这里的“主体”是剪辑与表演优先级，不要求固定百分比；不要让一条关键台词从头到尾都只听声音、不见说话者。

### 长台词反应镜头菜单

按剧情需要选用，不要求全部出现：

- **听者反应过肩**：从说话者肩后拍听者。说话者只作为前景肩背，继续的对白标记 `O.S.`。
- **听者动作特写**：握紧杯子、停下书写、后退半步、手指离开道具等，用动作证明台词造成的后果。
- **听者表情特写**：眼神停顿、呼吸变化、下颌收紧或短暂失焦；每个反应只承担一个清楚变化。
- **相关道具特写**：只在道具证明隐瞒、威胁、决定或因果时使用，不拿无关物件填时长。
- **在场 NPC 反应/动作**：只使用已经建立在空间里的 NPC，并让其反应服务群体压力、权力关系或信息扩散；反应要弱于核心角色且错峰发生。
- **回到说话者**：在关键词、情绪升级、句尾或等待回答前回到说话者单人主镜头/说话者过肩镜头。

推荐覆盖链：

```text
双人建立 → 说话者主镜头/说话者过肩 →
听者反应过肩或动作细节（说话者 O.S.）→
说话者主镜头/说话者过肩收尾 → 听者回答
```

### 声音、口型与轴线

- 从听者肩后看说话者：说话者在画内实说，要求对应口型。
- 从说话者肩后看听者：说话者不在画面主体内，持续对白标记 `O.S.`；听者不得错误对口型。
- 正反打保持同一轴线，视线方向互为对应。必须越轴时先用双人中性机位或可理解的运动建立新轴线。
- 对白跨镜保持同一音色、距离、混响和环境声。画外对白标记 `O.S./画外`，内心独白标记 `V.O./内心`。
- 多人反应错峰发生，禁止所有人同步点头、同步转头、同步笑或复制同一表情。

## 动作与道具特写

复杂动作按因果链拆解：

```text
准备 → 发力 → 接触 → 结果 → 身体反应 → 恢复/新姿态
```

- 全景证明空间、距离和动作可行；
- 中景表现主要发力与对抗；
- 特写只证明关键接触、机关、伤口或道具变化；
- 反应镜头表现结果，不让物体接触后直接跳到完全不同的姿势；
- 记录道具在哪只手、朝向、开合状态和镜尾位置。

## 危机建立

按强度递进：

1. **正常基线**：环境与人物行为正常，让观众知道空间规则。
2. **轻微异常**：远处声音、光影、风向、动物或道具出现一次偏差。
3. **验证异常**：人物停顿、回头、试探或靠近，异常留下可见证据。
4. **升级**：空间、声音或动作明确变危险，但仍不提前展示全部威胁。
5. **警戒/转场**：人物采取行动，镜尾给出进入下一批的明确方向或声音。

避免第一镜就展示高潮怪物或最终伤害。

## 跨场转场

选择一个可验证的连接锚：

- 动作匹配：挥手→下一场推门；
- 视线匹配：看向画外右→下一场目标位于画面左；
- 形状匹配：圆月→圆形灯；
- 遮挡转场：人物/帐帘/车辆填满画面；
- 声音先导：下一场声音提前进入；
- 光线匹配：火光闪白→日出；
- 速度方向匹配：主体保持相同运动方向。

记录 A 镜尾和 B 镜首的形状、位置、尺寸、方向、速度、光线与声音。没有共同锚点时宁可明确硬切，不假装“无缝”。

## 一镜到底

只有空间连通、动作连续且转场有物理路径时采用。

- 先画出人物路线和摄影机路线；
- 每次景别变化必须由距离、遮挡或主体运动产生；
- 以门、帘、柱、人物背部或快速甩镜隐藏必要转换；
- 不同时要求固定机位、环绕、俯冲和稳定长焦观察；
- 一镜到底若承载多个场景，逐段检查光线、方向和声音的连续变化。
