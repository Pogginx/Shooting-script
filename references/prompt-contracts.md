# Seedance 分镜与提示词合同

只使用与目标版本和交付物匹配的合同。删除无关字段，不输出空模板。

## 生成批次表

```markdown
| 批次 | 全片范围 | 局部时长 | 模型/入口 | 镜头 | 参考素材 | 首帧状态 | 尾帧锚点 |
|---|---|---:|---|---|---|---|---|
```

全片范围用于剪辑；局部时长用于模型。一个批次内部的局部时间从 0 开始。

## Seedance 2.5：时间戳多镜头

适用于 11–30 秒、事件顺序或同步要求明确的批次。

```text
【素材绑定】
@图片1：用于[角色/场景/服装/首帧]，作用于[范围]。
@视频1：只参考[动作/运镜/节奏]，不要继承[原人物/背景/品牌/音轨]。
@音频1：用于[音色/BGM/节奏]，作用于[范围]。

【全局设定】
[时长、画幅、题材、地点、时间、风格、光线、角色外形、道具归属]。
镜头总体逻辑：[稳定/手持/长焦观察/单一运动能量]。

【时间线】
0–4 秒：[景别与机位]；[主体可见动作]；[摄影机运动]；[对白/声音]；结束在[状态]。
4–9 秒：从上一段的[状态]继续；[动作因果]；[镜头]；[声音]；结束在[状态]。
……
[最后区间]：[收束动作、最后画面与尾锚]。

【连续性保护】
保持[身份、服装、左右关系、道具、场景地理、光线、动作动量、声音]连续。
不要出现[本任务真实风险：身份交换/位置重置/字幕/BGM/多余人物/错误道具等]。
```

时间区间必须为整数秒、有序、不重叠并覆盖整批。不要用时间戳控制一秒内多次高频动作。

## Seedance 2.5：镜头编号

适用于简单任务、时间点不关键或用户更关注自然节奏的批次。

```text
【素材绑定】[逐项说明用途、范围和排除项]
【整体】[一句话事件、风格、画幅、声音策略]

镜头 1：[谁]在[哪里]做[可见动作]；[景别/机位/运镜]；镜尾[状态]。
镜头 2：承接[上一镜状态]；[新信息或反应]；[景别/机位/运镜]；镜尾[状态]。
镜头 3：[高潮或收束]；结束在[可作为下一批锚点的画面]。

全程保持[连续性]；不要[任务相关禁项]。
```

## Seedance 2.0：兼容镜头顺序

最终提示词不要写精确 `0–3 秒`区间。母版仍保留准确时长，模型提示词改用自然镜头顺序。

```text
【参考素材】
Maya @图片1：人物身份和服装。
主帐 @图片2：空间布局、火盆位置和暖光。
@视频1：只参考跟拍节奏，不继承原人物和场景。

【整体】
[题材、画幅、整体气氛、声音策略]。按以下镜头自然分配节奏：

镜头 1：[谁 + 在哪里 + 做什么 + 摄影机如何观察]；结束在[状态]。
镜头 2：承接[状态]；[动作/表演/视角变化]；结束在[状态]。
镜头 3：[高潮/转折/收束]；最后停在[尾帧锚点]。

保持 Maya @图片1 的身份、服装与左右关系；保持主帐 @图片2 的布局和光线。
不要出现[字幕/BGM/额外角色/身份复制/场景漂移等实际风险]。
```

同一角色每次出现时尽量保持同一种绑定写法。不要用一张多人多视角拼图替代清楚的单人参考。

## 跨批次延长

```text
参考 @视频1 向后延长 [新增时长]。
原视频保持不变；新增部分从 @视频1 尾帧的以下状态继续：
[角色位置、朝向、动作动量、道具、镜头运动、光线、声音]。

[用目标版本允许的时间戳或镜头编号描述新增动作]

连接点保持[身份、场景地理、速度、方向、光影、声音]连续。
不要硬切、跳帧、闪烁、位置重置或凭空增加人物/道具。
```

“延长时长”是新增部分，不是最终视频总长。

## 首尾帧 / 独立关键帧

### 关键帧图像提示词

```text
镜头 [编号] 的定帧，用于锁定构图、角色身份和光线。
[角色外形与唯一辨识标记]；[景别、角度、人物位置、朝向]；
[场景结构、前中后景]；[主光方向、色温、材质与色调]。
单一可信瞬间，无运动模糊，不新增参考图中不存在的关键物体。
```

### 关键帧到视频

```text
@图片1 为首帧并锁定身份、构图、场景与光线。
[按版本写时间戳或镜头顺序，只描述动作、运镜和声音]。
摄影机移动时光源仍固定在场景空间中；不要改变角色比例、服装、道具和场景布局。
```

## 母版分镜行

每行至少能回答：

```text
镜号 / 全片时间 / 时长 / 本镜功能 / 景别焦段 / 机位运镜 /
可见动作 / 表演与台词 / 声音 / 镜尾状态 / 连续性 / 所属批次
```

镜尾状态必须具体，例如“她的右手停在帐帘边，视线锁向画外左侧”，不要只写“悬念感”。

## 最终校验

- 2.5 时间戳是否为整数秒并完整覆盖批次；
- 2.0 是否使用镜头编号而非伪精确秒控；
- 每个素材是否实际存在并有明确职责；
- 相邻镜头的角色、道具、动作、轴线、光线与声音是否承接；
- 参考视频是否写了不继承项；
- 对白是否能在母版时长内自然说完；
- 最后交付是否包含一段完整、可复制的逐批提示词。
