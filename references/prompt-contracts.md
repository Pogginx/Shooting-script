# Seedance 分镜与提示词合同

只使用与目标版本和交付物匹配的合同。删除无关字段，不输出空模板。

## 生成批次表

```markdown
| 批次 | 全片范围 | 局部时长 | 模型/入口 | 镜头 | 参考素材 | 首帧状态 | 尾帧锚点 |
|---|---|---:|---|---|---|---|---|
```

全片范围用于剪辑；局部时长用于模型。一个批次内部的局部时间从 0 开始。

## 平台中立：详细逐镜拍摄提示词

用户要求“提示词模板”“详细分镜”“逐镜拍摄提示词”或需要导演/摄影直接执行的版本时使用。先输出一次全局拍摄合同，再展开每个镜头。下面是字段合同，不是要求把所有空占位符原样交给用户；没有内容的字段删除。

### 全局拍摄合同

```text
# 全局拍摄合同

【对白与成片声音】
对白语言：[保留剧本语言 / 英文原声 / 中文原声 / 其他]。
口型：[画面内实说者对应实际对白语言；O.S./V.O. 段不要求画外角色口型]。
CN（制作参考）：[仅供制作理解，不进入画面 / 不适用]。
字幕：[不生成 / 指定语言与样式]。
BGM：[无 / 指定音乐职责与进入范围]。

【人物整体表演】
[人物A]：[核心性格、当前目标、情绪强度、动作节奏、克制方式]。
[人物B]：[……]。
[人物C]：[……]。

【多人反应】
反应必须错峰发生；直接受影响者先，隐藏利益相关者后，背景 NPC 最后且更克制。
禁止所有人同步点头、同步转头、同步笑或复制同一种表情。

【灯光与场景】
严格延续[参考图/已建立场景]的[主光方向、色温、实景光源、曝光与材质]。
不得凭空新增[未确认门窗、通道、灯具、固定物]。

【特效与剧情禁入】
本场允许出现：[明确的特效白名单；没有则写“无额外特效”]。
镜头[编号]之前禁止提前出现：[形态变化、伤势、战斗结果、剧情视觉或高潮特效]。

【全局摄影禁项】
[仅写本项目真实风险，例如：越轴、绕拍、穿墙、快速旋转、突然变焦、身份交换、道具跳手]。
```

除非用户明确指定，否则保留剧本对白语言，不自动改成英文。若剧本本身采用“英文原声＋中文括号翻译”且用户要求使用本详细模板，默认英文是实际对白、口型对应英文、中文只用于制作理解，并采用无字幕、无 BGM 的模板预设；用户或剧本有相反要求时以其为准。字幕设为“不生成”时，中文参考不能进入画面。

### 单镜详细合同

```text
## 镜头 [N]｜[全片起点–终点]｜[时长]
[焦段]mm｜[景别]｜[机位]｜[运镜]｜本镜功能：[一个主要功能]

### 机位 / 调度
摄影机位置：[相对人物、场景锚点、距离和高度]。
画面人物关系：[人物A画左/中/右、朝向、前中后景、遮挡关系]。
镜头运动：[固定 / 横摇 / 微推 / 后撤 / 跟拍；只保留一个主运动能量]。
本镜禁项：[绕拍 / 越轴 / 突然推近 / 快速旋转 / 穿越人物或场景固定物中的真实风险]。

### 画面 / 动作
[局部时间段]：[主体的第一个可见动作]。
[局部时间段]：[承接动作；写清准备、发力、接触、反应或恢复]。
[局部时间段]：[最后动作或信息]。
镜尾状态：[具体动作、视线、站位、道具、声音或遮挡，供下一镜承接]。

### 人物表演
[人物A]：眼神[……]；表情[……]；身体[……]；动作节奏[……]；情绪[……]。
[人物B]：[只写本镜实际可见的表演]。
表演重点：[本镜真正承担的心理、关系或剧情作用]。
具体禁项：[本镜不应出现的夸张表演、同步反应或提前情绪]。

### 台词 / 覆盖 / 口型
[人物A] [EN/CN/其他]（在画实说）：
“[实际对白]”
[CN 制作参考，如需要]：“[翻译；不进入画面]”
主覆盖：[说话者单人主镜头 / 从听者肩后看说话者的过肩镜头]。
口型：[人物A对应实际对白语言]。

切反应时：
[人物A] O.S.：“[跨镜继续的对白]”
反应画面：[从人物A肩后拍人物B / 人物B动作特写 / 人物B表情特写 / 在场NPC错峰反应]。
回切点：[关键词、情绪转折、句尾或等待回答前回到人物A]。

无台词时写：无台词。

### 声音 / 特效
环境声：[……]。
动作声：[……]。
对白状态：[近距离在画 / O.S. / V.O. / 远处]。
特效：[允许出现的可见/声音特效；没有则写“无额外特效”]。

### 连续性 / 禁止项
必须保持：[人物左右与视线、道具位置和手别、动作承接、场景结构、光线方向、服装伤势、声音空间]。
禁止：[人物瞬移、道具消失、突然换手、错误转身、错误口型、提前触发下一段剧情、不合理特效，以及本镜真实风险]。
```

全片时间码用于剪辑校验；“画面 / 动作”中的局部时间从本镜 0 开始。Seedance 2.0 的最终模型提示词不要保留精确秒段，只把这些局部时间用于母版和剪辑规划，再改写成“镜头 1 / 镜头 2”的自然顺序。

### 对白覆盖示例

下面演示一条长台词如何保持说话者为主体，同时切听者和在场 NPC 反应：

```text
镜头 08｜12 秒长台词
0–4 秒：从人物B肩后看人物A；人物A在画实说并对应口型，完成台词开场。
4–7 秒：从人物A肩后拍人物B的克制反应；人物A对白连续，标记 O.S.。
7–9 秒：人物B握紧杯沿的动作特写；人物A O.S. 说到信息转折。
9–10 秒：已经建立在场的NPC先停笔、后抬眼，反应错峰；人物A O.S.。
10–12 秒：回到人物A单人主镜头，人物A在画说完关键词并等待回答。
```

短台词不要强行套用这个覆盖链。反应镜头必须提供新信息；无关空镜、重复表情或凭空新增 NPC 不能用来填时长。若每个镜头/批次会被单独复制到模型，应把与该镜相关的全局约束一并注入；同一完整文档中则避免逐镜机械重复无变化的全局段落。

## Seedance 2.5：时间戳多镜头

适用于 11–30 秒、事件顺序或同步要求明确的批次。

```text
【素材绑定】
@图片1：用于[角色/场景/服装/首帧]，作用于[范围]。
@视频1：只参考[动作/运镜/节奏]，不要继承[原人物/背景/品牌/音轨]。
@音频1：用于[音色/BGM/节奏]，作用于[范围]。

【全局设定】
[时长、画幅、题材、地点、时间、风格、光线、角色外形、道具归属]。
镜头总体逻辑：[稳定/手持/长焦观察/单一运动能量]。

【时间线】
0–4 秒：[景别与机位]；[主体可见动作]；[摄影机运动]；[对白/声音]；结束在[状态]。
4–9 秒：从上一段的[状态]继续；[动作因果]；[镜头]；[声音]；结束在[状态]。
……
[最后区间]：[收束动作、最后画面与尾锚]。

【连续性保护】
保持[身份、服装、左右关系、道具、场景地理、光线、动作动量、声音]连续。
不要出现[本任务真实风险：身份交换/位置重置/字幕/BGM/多余人物/错误道具等]。
```

时间区间必须为整数秒、有序、不重叠并覆盖整批。不要用时间戳控制一秒内多次高频动作。

对白镜头应写明“说话者在画主镜头/说话者过肩＋对应口型”，或“切听者/动作反应＋说话者 O.S.”。长台词反应切镜仍要在关键词或收尾回到说话者，不要只写“人物对话”让模型自行决定错误口型。

## Seedance 2.5：镜头编号

适用于简单任务、时间点不关键或用户更关注自然节奏的批次。

```text
【素材绑定】[逐项说明用途、范围和排除项]
【整体】[一句话事件、风格、画幅、声音策略]

镜头 1：[谁]在[哪里]做[可见动作]；[景别/机位/运镜]；镜尾[状态]。
镜头 2：承接[上一镜状态]；[新信息或反应]；[景别/机位/运镜]；镜尾[状态]。
镜头 3：[高潮或收束]；结束在[可作为下一批锚点的画面]。

全程保持[连续性]；不要[任务相关禁项]。
```

## Seedance 2.0：兼容镜头顺序

最终提示词不要写精确 `0–3 秒`区间。母版仍保留准确时长，模型提示词改用自然镜头顺序。

```text
【参考素材】
Maya @图片1：人物身份和服装。
主帐 @图片2：空间布局、火盆位置和暖光。
@视频1：只参考跟拍节奏，不继承原人物和场景。

【整体】
[题材、画幅、整体气氛、声音策略]。按以下镜头自然分配节奏：

镜头 1：[谁 + 在哪里 + 做什么 + 摄影机如何观察]；结束在[状态]。
镜头 2：承接[状态]；[动作/表演/视角变化]；结束在[状态]。
镜头 3：[高潮/转折/收束]；最后停在[尾帧锚点]。

保持 Maya @图片1 的身份、服装与左右关系；保持主帐 @图片2 的布局和光线。
不要出现[字幕/BGM/额外角色/身份复制/场景漂移等实际风险]。
```

同一角色每次出现时尽量保持同一种绑定写法。不要用一张多人多视角拼图替代清楚的单人参考。

2.0 提示词虽然不写精确秒点，仍要保持对白覆盖顺序：说话者主镜头或说话者过肩为主体；切听者反应时把持续对白标记 `O.S.`，再自然回到说话者。不要让听者或背景 NPC 错误对口型。

## 跨批次延长

```text
参考 @视频1 向后延长 [新增时长]。
原视频保持不变；新增部分从 @视频1 尾帧的以下状态继续：
[角色位置、朝向、动作动量、道具、镜头运动、光线、声音]。

[用目标版本允许的时间戳或镜头编号描述新增动作]

连接点保持[身份、场景地理、速度、方向、光影、声音]连续。
不要硬切、跳帧、闪烁、位置重置或凭空增加人物/道具。
```

“延长时长”是新增部分，不是最终视频总长。

## 首尾帧 / 独立关键帧

### 关键帧图像提示词

```text
镜头 [编号] 的定帧，用于锁定构图、角色身份和光线。
[角色外形与唯一辨识标记]；[景别、角度、人物位置、朝向]；
[场景结构、前中后景]；[主光方向、色温、材质与色调]。
单一可信瞬间，无运动模糊，不新增参考图中不存在的关键物体。
```

### 关键帧到视频

```text
@图片1 为首帧并锁定身份、构图、场景与光线。
[按版本写时间戳或镜头顺序，只描述动作、运镜和声音]。
摄影机移动时光源仍固定在场景空间中；不要改变角色比例、服装、道具和场景布局。
```

## 母版分镜行

每行至少能回答：

```text
镜号 / 全片时间 / 时长 / 本镜功能 / 景别焦段 / 机位运镜 /
可见动作 / 表演与台词 / 对白覆盖与在画或O.S.状态 / 口型 / 声音 /
镜尾状态 / 连续性 / 所属批次
```

镜尾状态必须具体，例如“她的右手停在帐帘边，视线锁向画外左侧”，不要只写“悬念感”。

## 最终校验

- 2.5 时间戳是否为整数秒并完整覆盖批次；
- 2.0 是否使用镜头编号而非伪精确秒控；
- 每个素材是否实际存在并有明确职责；
- 相邻镜头的角色、道具、动作、轴线、光线与声音是否承接；
- 参考视频是否写了不继承项；
- 对白是否能在母版时长内自然说完；
- 最后交付是否包含一段完整、可复制的逐批提示词。
